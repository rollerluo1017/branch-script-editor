# 分支剧本编辑器

用来写分支游戏剧本的小工具：主线、支线、大量选项分支、多结局。只有一个网页文件，不用安装，也不用联网。

## 怎么打开

- **本地使用**：下载 `index.html`，双击用 Chrome 或 Edge 打开。
- **在线使用**：如果仓库开启了 GitHub Pages，直接打开 Pages 链接就能用。

内容自动保存在当前浏览器里。换电脑、换浏览器或清理缓存之前，请先用“文件 → 导出 JSON”备份。

## 主要功能

- **分支图画布**：双击空白处新建节点；拖动选项右侧的圆点连线，拖到空白处会自动新建节点；滚轮缩放，拖动空白处平移。
- **节点编辑**：标题、类型（主线/支线/结局）、章节、正文、选项。正文里写 `角色名：台词` 会显示成对话，写 `{变量名}` 会显示变量值。
- **变量、条件和效果**：选项可以设出现条件（如 `好感 >= 3 && 有钥匙`）和选择后的效果（如 `好感 += 1; 有钥匙 = true`）。
- **试玩**：从开始节点或任意节点像玩游戏一样点下去，可以实时查看和修改变量。
- **检查**：找出死路、没连上的选项、走不到的节点；“按条件模拟所有路线”会列出每个结局能否达成，以及一条最短路线。
- **多项目**：左上角“📁 项目”可以新建、复制、切换、删除项目，示例剧本单独保留。
- **导入导出**：JSON（备份或发给朋友）、Markdown 剧本文本。

## 和朋友共享

对方点“文件 → 导出 JSON”把文件发给你，你点“文件 → 导入 JSON”，就会多出一个标着“（导入）”的项目。以后对方再发新版本，导入时选择更新那份导入的项目就行，不会影响你自己的项目。
